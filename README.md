# EzPanelMaker | ایزی پنل ماکر

ربات تلگرام برای ساخت و مدیریت خودکار **پنل زئوس (Zeus Panel)** روی Cloudflare Workers + D1.

**آیدی ربات:** [@EzPanelMakerBot](https://t.me/EzPanelMakerBot)

## ویژگی‌ها

- عضویت اجباری در کانال (قابل تنظیم)
- دکمه‌های اسپانسر (دانلودر اینستاگرام + V2ray_company)
- ثبت اکانت کلودفلر با توکن API
- ساخت خودکار پنل زئوس (دانلود سورس رسمی + ساخت D1 + دیپلوی Worker + فعال‌سازی workers.dev)
- مدیریت و آپدیت پنل‌های قبلی
- ذخیره اطلاعات کاربران و اکانت‌ها در SQLite

## استقرار روی Railway

1. ریپو را در GitHub بساز و این فایل‌ها را آپلود کن.
2. در [Railway](https://railway.app) یک پروژه جدید بساز و ریپو را متصل کن.
3. در بخش **Variables** این متغیرها را اضافه کن:

```
BOT_TOKEN=توکن_ربات_از_BotFather
REQUIRED_CHANNEL=نام_کانال_بدون_@
ADMIN_IDS=آیدی_تلگرام_ادمین (اختیاری)
```

4. اگر می‌خواهی دیتابیس پایدار باشد، یک **Volume** به مسیر `/app` یا جایی که `ezpanel.db` ذخیره می‌شود اضافه کن و `DB_PATH` را تنظیم کن.
5. Deploy را بزن. ربات شروع به کار می‌کند.

## متغیرهای محیطی

| متغیر | توضیح | اجباری |
|-------|-------|--------|
| `BOT_TOKEN` | توکن ربات تلگرام | بله |
| `REQUIRED_CHANNEL` | نام کانال برای عضویت اجباری (بدون @) | خیر (اگر خالی باشد عضویت چک نمی‌شود) |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (با کاما جدا) | خیر |
| `ZEUS_SOURCE_URL` | آدرس سورس زئوس (پیش‌فرض رسمی) | خیر |
| `DB_PATH` | مسیر فایل دیتابیس SQLite | خیر (پیش‌فرض: ezpanel.db) |

## اجرا محلی

```bash
python -m venv venv
source venv/bin/activate   # ویندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# فایل .env را ویرایش کن
python bot.py
```

## نکات امنیتی

- **هرگز** توکن ربات یا توکن‌های کلودفلر کاربران را در کد یا گیت عمومی قرار نده.
- توکن‌های کلودفلر کاربران در دیتابیس لوکال ذخیره می‌شوند. روی Railway از Volume استفاده کن.
- لایسنس پنل زئوس Proprietary است؛ ربات فقط سورس را از ریپوی رسمی دانلود و روی اکانت خود کاربر دیپلوی می‌کند.

## ساختار منو

1. **ساخت پنل جدید** → لیست اکانت‌های ثبت‌شده → دیپلوی
2. **مدیریت و آپدیت پنل‌ها** → انتخاب پنل → آپدیت سورس
3. **ثبت اکانت کلودفلر** → راهنما + لینک ساخت توکن → دریافت توکن

## پشتیبانی

اگر خطایی دیدی لاگ‌های Railway را چک کن. خطاهای رایج معمولاً مربوط به پرمیشن توکن کلودفلر یا محدودیت رایگان D1 است.
