# EzPanelMaker

ربات Telegram برای ثبت توکن Cloudflare و ساخت/آپدیت یک Worker پنل زئوس.

## اجرا در Replit یا هر سرور Python

1. فایل‌های این پوشه را در GitHub قرار دهید.
2. در Replit یک پروژهٔ Python بسازید و از GitHub ایمپورت کنید.
3. از بخش Secrets متغیرهای فایل `.env.example` را اضافه کنید. توکن را در GitHub یا کد قرار ندهید.
4. نصب و اجرا:

```bash
pip install -r requirements.txt
python bot.py
```

توکن Cloudflare باید دسترسی ساخت Worker و خواندن Workers Subdomain را داشته باشد. اگر `workers.dev` برای اکانت فعال نباشد، Cloudflare اجازهٔ ساخت لینک دائمی را نمی‌دهد؛ یک‌بار آن را از داشبورد Cloudflare فعال کنید.

## نکته‌های مهم

- Telegram برای Inline Keyboard رنگ واقعی ندارد؛ رنگ‌های سبز/آبی/سفید/قرمز در متن دکمه با ایموجی مشخص شده‌اند.
- `@FaraDownloaderBot` یک ربات است و قابل بررسی به‌عنوان عضویت کانال نیست؛ برای اجبار عضویت، مقدار `SPONSOR_CHANNEL` را به یوزرنیم واقعی یک کانال تغییر دهید و ربات را در آن کانال ادمین کنید.
- داده‌ها در SQLite ذخیره می‌شوند تا با restart عادی Replit از بین نروند. فایل دیتابیس نباید commit شود.
- کدی که همراه درخواست فرستاده شده بود، توکن را داخل فایل متنی داشت. قبل از استفادهٔ این نسخه، آن توکن را در Cloudflare revoke کنید و یک توکن جدید بسازید.
- فایل ارسالی شامل سورس کامل پنل زئوس نبود؛ Worker فعلی یک صفحهٔ پایهٔ سالم و قابل‌دسترسی می‌سازد. برای قرار دادن UI/API واقعی پنل، تابع `worker_source()` را با سورس پنل خودتان جایگزین کنید.
